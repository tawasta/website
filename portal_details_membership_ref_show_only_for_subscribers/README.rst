========================================================
Portal Details Membership Ref: Show only for Subscribers
========================================================

* Membership Reference visibility in Portal details (/my/account/) sidebar
  is limited to users with an ongoing subscription.
* Intended for situations where also non-member users may have portal accounts, 
  and their partner record may have the `ref` field auto-filled in by e.g.
  the `base_partner_sequence` module.


Configuration
=============
* None needed

Usage
=====
* Log in to that partner's My Account view to conditionally see the 
  field in the sidebar
