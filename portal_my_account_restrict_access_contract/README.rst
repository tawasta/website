=============================================================
Portal: Restrict Access to Menuitems in My Account (contract)
=============================================================

* Enables restricting access to Contracts in Portal
* Hides menuitem and prevents accessing the related routes
* Intended for situations where an user should be able to view
  only certain type of content in portal, but not everything

Configuration
=============
* In backend contact form, set the "Portal: Hide Contract-related menuitems"
  checkbox for relevant partners that have a portal account

Usage
=====
* Open portal's my account view as a user with restricted access.
  Menuitems are hidden and routes disabled
