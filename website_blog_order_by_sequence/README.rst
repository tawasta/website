===============================
Website Blog: Order by Sequence
===============================
* Add a sequence field and use it when ordering blogs on website

Configuration
=============
* Go to website -> settings -> blogs and drag the blogs into the
  desired order in the list view

Usage
=====
* Navigate to /blog in frontend to see the new order
