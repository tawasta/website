==============================
website_blog_snippet_templates
==============================

This Odoo module extends the dynamic blog post snippet in the Website Builder with **customizable, responsive layout options**. It includes two templates: a minimalist **Clean list layout** and a visual **Card-style layout** — both designed to fit modern design needs.


Features
========

- Clean list-style layout for blog posts
- Optional display toggles for:
  - Cover image
  - Tags
  - Blog name
- Card-style layout with image and metadata
- Automatic responsive column layout
- Fully editable via the Odoo Website Builder
- No configuration required

Configuration
=============

No configuration needed. Install the module and start using the layouts in the Website Editor.

Usage
=====

1. Go to **Website → Edit**.
2. Drag and drop the **Blog Posts** snippet into your page.
3. Open the snippet options:
   - Choose your preferred layout:  
     **Clean list layout** or **Card-style layout**
   - Toggle visibility for:
     - Post image  
     - Tags  
     - Blog name  
4. Adjust the column count from the section settings if needed (e.g., 2, 3, 4).
5. Save and publish the page.
