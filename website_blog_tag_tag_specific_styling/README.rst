==================================
Website Blog: Tag-Specific Styling
==================================
* Add classes to blog-related DOM elements, to be then styled
  with website builder's CSS editor

Configuration
=============
* Go to website -> settings -> blog -> tags and give them the
  desired CSS classes
* Use frontend website editor for the actual styling of those
  classes

Usage
=====
* Open blog listing or individual blog page after having
  defined the CSS with website editor.
