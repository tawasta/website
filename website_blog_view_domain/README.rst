=======================================
Website Blog: blog_id domain by website
=======================================

Configuration
=============
No configuration is required after installation.

Usage
=====
When creating a new blog post from the website interface, the available
blog selection (``blog_id``) is filtered based on the active website.

Users who are not members of the group
``website_manager_group.group_website_manager`` will only see blogs that:

- Belong to the current website, or
- Have no website assigned.

Website managers can see all blogs without restrictions.
